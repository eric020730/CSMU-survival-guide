如何更新

點「新增紀錄」，填好標題、分類與內容，再按「前往 GitHub 發佈」。

  1. 登入你的 GitHub 帳號。
  2. 確認新檔案的內容，按 Commit changes，提交到 main。
  3. 等 GitHub Actions 發佈完成，重新整理網站即可看到新紀錄。

文章下方的「在 GitHub 編輯」可以修改已有紀錄。也可以直接把新經驗告訴 Codex，請它整理、推送並確認上線。

草稿只保存在目前的瀏覽器。要跨裝置保留，請提交到 GitHub，或先下載 Markdown 備份。
