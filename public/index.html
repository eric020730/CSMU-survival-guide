  1. 先寫下一篇紀錄

    填標題、選分類、寫內容。可以切到「閱讀預覽」，確認排版。

  2. 到 GitHub 確認提交

    按「前往 GitHub 發佈」，登入後確認檔案內容，再按 Commit changes 提交到 main。

  3. 等網站更新

    GitHub Actions 發佈完成後，重新整理就會看到新紀錄。
